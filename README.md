# DnF_Battle_C_01

# 던전앤파이터 전투 시스템 AI기반 설계 및 구현

    플레이어는 캐릭터생성 한다.

            플레이어id, 캐릭터명, 직업(전사/마법사), 레벨을 입력한다.

            반드시 플레이어체크를 한다. (플레이어id는 "hero")

            직업에 따라 기본 능력치가 다르게 설정된다.

                · 전사 : HP = 레벨 × 100, 공격력 = 레벨 × 15 (물리 공격)

                · 마법사 : HP = 레벨 × 60, 공격력 = 레벨 × 25 (마법 공격)

    플레이어는 몬스터공격 한다.

            반드시 플레이어체크를 한다.

            직업에 따라 스킬이 다르게 발동된다.

                · 전사: "검 휘두르기!" -> 데미지 = 공격력 × 1.5

                · 마법사: "파이어볼" -> 데미지 = 공격력 × 2.0

            데미지에 따라 등급을 부여한다.

                · S급 공격: 데미지 200 이상

                · A급 공격: 데미지 100 이상

                · B급 공격: 데미지 100 미만

    모든 명칭은 한글로 : Use Case명, 클래스명, 속성명, 행위명 (데이터타입은 영문)

    GitHub에 Repository 생성하여 산출물 관리 (Repository명 : "Dnf_Battle_C_01")

    사용사례 다이어그램(Use Case Diagram)을 정의하시오.

        (Use Case는 "캐릭터생성", "몬스터공격", "플레이어체크" 만 있음)

    클래스 다이어그램(Class Diagram)을 설계하시오.

        (Class는

            · '플레이어(행위: 플레이어체크)'

            · '캐릭터(추상클래스, 속성: 캐릭터명/레벨/HP/공격력, 행위: 스킬발동)'

            · '전사(캐릭터 상속, 행위: 스킬발동 - 검 휘두르기)'

            · '마법사(캐릭터 상속, 행위: 스킬발동 - 파이어볼)'

            · '전투(행위: 캐릭터생성, 몬스터공격)'

        과 <<boundary>> 클래스 ("Create_Character_UI", "Attack_Monster_UI") 만 있음.)

    순차도(Sequence Diagram)를 설계하시오. (캐릭터생성, 몬스터공격)

    순차도(Sequence Diagram)를 기반으로 구현하시오. (캐릭터생성, 몬스터공격)

    실행은 JSP 로 실행할 것. (처리 결과가 출력되도록 할 것)

    모든 설계 및 구현은 위 요구사항 범위내에서 수행할 것

    설계와 구현의 일관성을 유지할 것
